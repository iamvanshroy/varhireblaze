A Short History of Browser Games

Browser games have been around almost as long as web browsers themselves. Their story is really the story of the web growing up, from static pages to a platform powerful enough for fast, smooth games on any device.

The early web: text and turns

The first web games in the 1990s were simple. Pages reloaded after every move, so games were turn-based: text adventures, quizzes, and multiplayer worlds played through forms and links. They were slow, but they proved people wanted to play right inside the browser.

The plug-in era

To get real animation and sound, browsers relied on plug-ins, extra programs installed alongside the browser. Java applets and, above all, Adobe Flash powered a huge wave of web games in the 2000s. A whole generation of designers and developers started their careers making small Flash games that spread across portals and school computer labs.

Plug-ins had problems, though. They were a common target for security attacks, drained laptop batteries and mostly didn't work on smartphones. Adobe officially ended support for Flash at the end of 2020, and browsers removed it.

HTML5 changes everything

Through the 2010s, browsers added the features games needed directly into the web standards:

  • Canvas for fast 2D drawing.
  • WebGL for hardware-accelerated 3D graphics.
  • Web Audio for sound effects and music, even generated live.
  • Touch events, so games could work on phones and tablets.
  • Gamepad API, so you can even plug in a controller.

Now a game could run in any modern browser on any device, with nothing extra to install.

Today: WebAssembly and WebGPU

WebAssembly lets code written in languages like C++ and Rust run in the browser at close to native speed, so even big game engines can export to the web. WebGPU, a newer graphics standard, gives web games more direct access to modern graphics cards.

Why browser games are back

  • Instant: share a link and your friend is playing in seconds.
  • Light: no storage space, no updates, nothing to uninstall.
  • Everywhere: one game works on a laptop, a phone and a school computer.
  • Short sessions: perfect for a 5-minute break between tasks.
